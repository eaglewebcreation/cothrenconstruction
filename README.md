# Cothren Plumbing & Construction website

Static site (HTML, CSS, JS, no build step). Built by Eagle Web Creation.

- `main` deploys the preview; `staging` deploys the test site.
- Pages: index, services, work, contact, faq. Clean URLs come from `.htaccess`.
- Pages carry a noindex meta tag until launch.
- Forms post to FormSubmit (cothrenplumbing@gmail.com).
